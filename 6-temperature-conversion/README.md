# 🌡️ Temperature Converter App

A lightweight, modern web application designed to convert temperatures between Celsius (°C) and Fahrenheit (°F). This project is built entirely using vanilla web technologies (HTML, CSS, and JavaScript) to maximize performance and strengthen core programming logic.

## 🚀 Key Features

- **Two-Way Conversion:** Seamlessly and accurately convert from °C to °F and vice versa with a single click.
- **Smart Data Validation:** Utilizes a dedicated validation function to check input data. Automatically detects and alerts the user if the input field is empty or contains non-numeric characters (`NaN`).
- **Modern UI/UX:** Designed with a minimalist layout featuring a soothing mint green color palette, smooth rounded corners (`border-radius`), and interactive `:hover` and `:active` states for buttons.
- **Clean Code Architecture:** Strictly follows the DRY (Don't Repeat Yourself) principle and implements proper Variable Scope for optimal memory management and code reusability.
