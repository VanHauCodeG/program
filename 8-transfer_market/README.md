# ⚽ FC Online Market Manager

A lightweight, high-performance web application designed to simulate the FC Online Transfer Market. Built entirely using Vanilla JavaScript, HTML5, and CSS3.

## 🚀 Live Demo Features
- **Real-time Search:** Instantly filters players using `.filter()` and `.includes()` as you type.
- **Dynamic State Management:** Tracks user balances and active lists to fix dynamic index-shifting bugs.
- **Responsive Layout:** Dark-themed UI crafted with CSS Grid for a premium gaming atmosphere.

## 🛠️ Built With
- **HTML5**: Semantic web structure.
- **CSS3 (Grid/Flexbox)**: Smooth animations, active scale effects, and hover transitions.
- **Modern JavaScript (ES6)**: Dom manipulation, Array methods (`.map()`, `.filter()`), and String sanitization (`.trim()`, `.toLowerCase()`).
