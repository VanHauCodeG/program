# 📚 Book Manager Application

A simple yet powerful Web-based Book Management Application that allows users to seamlessly manage a list of books (View, Add, Delete). The project features a clean, responsive UI/UX with smooth interactive feedback.

---

## 🚀 Key Features

- **Core CRUD Operations:** View the current list of books, add new books (with data input validation), and remove books from the system.
- **Enhanced UI/UX:**
  - Perfectly aligned form layout with balanced spacing.
  - Interactive element animations (`hover`, `active`, and a subtle `scale` effect on button clicks).
  - Cleaned up default browser focus highlights (`outline: none`), replacing them with a sleek, neon-green glow.
- **Custom Branding:** Integrated a subtle, fixed copyright signature positioned perfectly at the bottom center of the screen.

---

## 🛠️ Tech Stack

Built purely with modern, foundational web technologies:
- **HTML5:** Semantic layout structure.
- **CSS3 (Modern Layouts):** Powered by Flexbox, `position: fixed`, smooth `transition` effects, and coordinate manipulation using `transform`.
- **JavaScript (ES6+):** Asynchronous logic (`async/await`) for API communication and dynamic DOM rendering.
