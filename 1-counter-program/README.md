# 🔢 Counter Program

A simple, clean, and responsive Counter Application built with vanilla HTML, CSS, and JavaScript. This is my very first project on the journey to becoming a Full-stack Developer!

## 🚀 Features

- **Increase**: Increment the count by 1.
- **Decrease**: Decrement the count by 1.
- **Reset**: Reset the counter back to 0.
- Fully responsive card design with smooth UI interactive elements.

## 🛠️ Tech Stack

- **HTML5**: Structured layout with semantic tags.
- **CSS3**: Custom styling featuring Flexbox, custom color schemes, and box-shadows.
- **JavaScript (ES6+)**: DOM Manipulation and event handling.

## 🧠 What I Learned From This Project

- How to properly use `const` for DOM elements and `let` for mutable states (the counter variable).
- Solving minor syntax and naming convention bugs (camelCase properties like `textContent`).
- Structuring clean and reusable code by separating the UI update logic into a dedicated function.
