# 🧮 Quadratic Equation Solver

A modern, clean, and interactive web application designed to solve quadratic equations (ax^2 + bx + c = 0). This project showcases an advanced **AI-Assisted Development** workflow, where the algorithm and logic were architected by me, and the boilerplate coding was executed by an AI Agent.

## 🤖 Development Workflow (The "Tech Lead" Approach)

- **Architecture & Logic:** Designed 100% by me. I mapped out the entire mathematical algorithm in advance, including edge-case handling (empty inputs, non-number validations, and resolving linear equation traps when a = 0).
- **Execution:** Leveraged AI Agents as junior developers to write the clean HTML structure, custom CSS styling, and standard ES6+ JavaScript implementation based strictly on my architectural blueprint.

## 🚀 Key Features

- **Comprehensive Validation:** Automatically detects empty fields or invalid character inputs to prevent crashes.
- **Linear Equation Fallback:** Smartly handles cases where $a = 0$ and accurately solves the remaining linear form (bx + c = 0).
- **Delta Evaluation:** Calculates and displays discriminant (Delta) values, providing detailed feedback for all scenarios (Two distinct roots, one double root, or no real solutions).
- **Responsive & Modern UI:** Designed with a beautiful, centered mint-green container matching the overall Monorepo theme, complete with interactive `:hover` and `:active` button transitions.

## 🛠️ Core Concepts Applied

- Advanced DOM Manipulation and Event Handling.
- Mathematical reasoning and edge-case testing in JavaScript (`Math.sqrt()`).
- Responsive Web Design using CSS Flexbox/Grid.
