Welcome to my repository dedicated to mastering core **JavaScript (ES6+)** concepts, data structures, and algorithmic logic. This repository serves as a proven record of my continuous learning journey and commitment to writing clean, maintainable code.

## 📁 Repository Structure

Every folder represents a practical application of a specific programming concept:

* **`1-counter-program`**: Concepts applied: Variables, DOM Manipulation, Event Listeners.
* **`2-dice-program`**: Concepts applied: `Math.random()`, Function Scopes, UI Updates.
* **`3-calculator-program`**: Concepts applied: Arithmetic operators, String/Type conversion, Control flows.
* **`4-quadratic-program`**: Concepts applied: Complex mathematical logic, Conditional (`if/else`) handling.
* **`5-number-guess-game`**: Concepts applied: While/For loops, User input validation, State tracking.
* **`6-temperature-conversion`**: Concepts applied: Switch-case statements, Function arguments, and returns.
